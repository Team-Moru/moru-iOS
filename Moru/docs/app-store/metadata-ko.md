### 홍보 문구

### 상세 설명

MORU는 알람을 끄는 데서 끝나지 않고 아침 루틴 완료까지 이어준다. 내 목표에 맞춘 모닝 루틴을 설정하고 알람에서 바로 시작하세요. 화면을 계속 조작하지 않아도 온디바이스 음성 코칭이 흐름을 이어 줍니다. 확인형, 타이머형, 입력형 단계를 마치면 루틴 완료 결과가 기기에 로컬로 저장됩니다.

## 붙여넣기 필드 길이·바이트 표

글자 수는 붙여넣기 원문 기준 Unicode 문자 수이며, 키워드는 UTF-8 바이트 수입니다. 키워드의 쉼표와 공백도 바이트에 포함합니다.

| 필드 | 실제값 | 제한 | 결과 |
|---|---:|---:|---|
| 앱 이름 | 14자 | 2~30자 | PASS |
| 부제 | 12자 | 30자 이하 | PASS |
| 홍보 문구 | 52자 | 170자 이하 | PASS |
| 상세 설명 | 164자 | 4,000자 이하 | PASS |
| 키워드 | 93 UTF-8 bytes | 100 UTF-8 bytes 이하 | PASS |

키워드는 ASCII 쉼표로 구분했으며, 각 항목은 공백 제거 후 3자 이상입니다. 빈 항목, 대소문자 구분 없는 중복, 타사명·타 앱명, 앱 이름·부제의 불필요한 반복을 넣지 않았습니다.
