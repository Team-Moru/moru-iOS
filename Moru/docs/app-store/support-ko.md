# MORU 고객지원

## MORU 소개

MORU는 알람을 끄는 데서 끝나지 않고 아침 루틴 완료까지 이어준다. 목표에 맞춘 모닝 루틴을 만들고, 알람에서 바로 시작해, 화면을 계속 조작하지 않아도 이어지는 온디바이스 음성 코칭으로 단계를 진행할 수 있습니다. 확인형·타이머형·입력형 단계를 마친 결과는 현재 기기에 로컬로 저장됩니다.

## 지원 환경

- iOS 26.0 이상
- iPhone 및 iPad
- 알람 기능에는 AlarmKit 권한이 필요할 수 있음
- 음성 입력을 사용하는 코칭에는 마이크 및 음성 인식 권한이 필요할 수 있음

## 빠른 시작

1. 목표를 선택하고 내 아침에 맞는 모닝 루틴을 설정합니다.
2. 루틴에 확인형, 타이머형, 입력형 단계를 구성합니다.
3. 알람 시간, 요일, 로컬 음성 설정을 선택합니다.
4. 필요한 권한을 허용합니다.
5. 알람에서 MORU 루틴을 시작하고 단계별 흐름을 진행합니다.
6. 완료한 뒤 현재 기기에 저장된 루틴 결과를 확인합니다.

## 자주 묻는 질문

### 계정을 만들어야 하나요?

아니요. MORU는 계정을 요구하지 않으며 개발자 운영 서버도 사용하지 않습니다. 루틴과 완료 결과를 포함한 데이터는 현재 기기에 로컬로 저장됩니다.

### 음성은 어디에서 처리되나요?

음성 코칭과 음성 입력은 기기 안에서 처리됩니다. 원본 음성은 저장하거나 전송하지 않으며, 서버 폴백도 없습니다. 전사문과 사용자가 입력한 내용은 기기에 로컬로 저장될 수 있습니다.

### 권한을 다시 허용하려면 어떻게 하나요?

iOS 설정에서 MORU를 열어 마이크, 음성 인식, 알람 관련 권한을 다시 허용합니다. 해당 권한이 꺼져 있으면 음성 입력 또는 알람 시작 기능을 사용할 수 없습니다.

## 알람이 예상대로 시작되지 않을 때

다음 순서대로 확인합니다.

1. AlarmKit 권한이 허용되어 있는지 확인합니다.
2. 앱 안에서 알람이 활성화·예약되어 있는지와 설정한 시간·요일을 확인합니다.
3. 기기의 음량과 현재 오디오 출력 장치를 확인합니다.
4. 알람을 다시 예약한 뒤 앱에서 다시 시도합니다.

문제가 계속되면 아래 문의 항목만 포함해 지원팀에 알려 주세요.

## 음성 코칭이 이어지지 않을 때

1. 마이크와 음성 인식 권한이 허용되어 있는지 확인합니다.
2. 기기의 음량과 현재 오디오 출력 장치를 확인합니다.
3. 주변을 조용하게 한 뒤 다시 시도합니다.
4. 앱을 다시 연 뒤 해당 루틴을 다시 시작합니다.

음성 문제를 문의할 때 원본 음성이나 전사문을 보내지 마세요. MORU는 이를 지원 요청에 요구하지 않습니다.

## 로컬 데이터 초기화와 삭제

현재 기기의 MORU 로컬 데이터를 초기화·삭제하려면 iOS에서 MORU 앱을 삭제합니다. 이 작업은 현재 기기의 앱 컨테이너와 그 안의 로컬 데이터를 제거합니다.

MORU에는 개발자 운영 서버나 앱 자체 동기화·백업 기능이 없습니다. 다만 Apple OS의 기기 백업·복원에 앱 데이터가 포함되는지는 사용자의 Apple ID, 기기 설정, OS 정책에 따라 달라지며, 개발자는 해당 백업에 접근할 수 없습니다. 따라서 앱 삭제는 모든 OS 관리 백업의 소멸을 보장하지 않고, 기기 변경 후 복원을 앱 기능으로 보장하지도 않습니다.

## 안전한 문제 보고

문제 보고에는 아래 정보만 포함해 주세요.

- 앱 버전
- iOS 버전
- 기기 모델
- 재현 단계

원본 음성, 전사문, 민감한 루틴 내용은 보내지 마세요.
지원 이메일 전송은 이용자의 자발적인 선택입니다. 운영자와 선정한 이메일 서비스 제공자는 문의 응답과 문제 해결만을 위해 보낸 사람 이메일 주소와 앱 버전, iOS 버전, 기기 모델, 재현 단계를 처리할 수 있습니다. 이는 MORU 앱의 자동 전송이 아니며, 보관·제공자·국외 이전 관련 상세는 연결된 개인정보 처리방침을 따릅니다.
