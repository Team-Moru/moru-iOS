# MORU

## 알람을 끄는 데서 끝나지 않고 아침 루틴 완료까지 이어준다.

아침 알람을 끈 뒤 무엇부터 해야 할지 다시 고민하지 않도록, MORU가 알람에서 루틴의 마지막 단계까지 한 흐름으로 연결합니다.

## 알람 이후의 아침까지 이어지는 루틴

하루를 시작할 때 필요한 것은 더 많은 화면 조작이 아니라 다음 행동으로 자연스럽게 이어지는 흐름입니다. MORU는 내 목표에 맞는 모닝 루틴을 알람과 연결하고, 한 단계씩 마칠 수 있도록 돕습니다.

## MORU로 하는 다섯 가지

### 내 목표에 맞춘 모닝 루틴 설정

내 아침에 맞는 목표를 선택하고 루틴을 구성합니다.

### 알람에서 바로 루틴 시작

예약한 알람에서 MORU 루틴을 바로 시작해 아침의 첫 행동을 이어 갑니다.

### 화면을 계속 조작하지 않아도 이어지는 온디바이스 음성 코칭

화면을 계속 확인하지 않아도 기기 안에서 이어지는 음성 코칭이 다음 흐름을 안내합니다.

### 확인형·타이머형·입력형 단계 수행

확인형, 타이머형, 입력형 단계로 내 흐름에 맞춰 하나씩 진행합니다.

### 루틴 완료 결과의 로컬 저장

마친 루틴의 완료 결과를 현재 기기에 로컬로 남깁니다.

## 내 기기 안에서 이어지는 경험

MORU는 음성 코칭과 음성 입력을 기기 안에서 처리합니다. 원본 음성은 저장하거나 전송하지 않으며, 전사문·자유 입력·루틴·완료 결과도 현재 기기에 저장됩니다. 개발자 운영 서버와 앱 자체의 동기화·백업 기능은 없고, 서버 폴백도 없습니다.

Apple OS의 기기 백업·복원에 앱 데이터가 포함되는지는 사용자의 Apple ID, 기기 설정, OS 정책에 따라 달라집니다. 이는 MORU의 앱 자체 백업 기능이 아니며 개발자는 해당 백업에 접근하지 않습니다.

## 시작하는 흐름

1. 목표를 선택해 모닝 루틴을 만듭니다.
2. 알람 시간과 요일을 정하고 필요한 권한을 허용합니다.
3. 알람에서 루틴을 시작합니다.
4. 음성 코칭과 단계별 흐름을 따라 진행합니다.
5. 완료 결과를 현재 기기에서 확인합니다.
