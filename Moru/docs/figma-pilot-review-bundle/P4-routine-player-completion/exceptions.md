# P4 Figma 예외

## 의도적으로 복제하지 않은 source 내용

- `1461:2561` 상단의 종료 설명 문구는 frame 밖 accidental layer leak로
  판단해 구현하지 않았다.
- `AI 음성 안내 중`은 실제 상태를 과장하므로 `음성 안내 중`으로,
  녹음 중 상태는 `음성 인식 중`으로 표시한다.
- `넘어갈께요`, `양팔 위로 쪽` 오탈자는 각각 `넘어갈게요`,
  `양팔 위로 쭉`으로 바로잡았다.
- 체험 완료의 계정 생성 CTA는 현재 앱 계약에 없는 navigation이다.
  기존 trial 비저장 계약과 `홈으로` callback을 유지했다.

## 동적 상태

- Figma 타이머는 진행 중인 `1:48`, 결정적 캡처는 최초 `3:00`이다.
  진행 값 차이는 기능 차이가 아니며 timer tick/자동 완료는 기존 로직과
  전체 테스트로 검증한다.
- Figma 음성 frame은 안내/전송 시점, 구현 fixture는 인식 session의
  결정적 시점이다. 안내/인식/결과를 각각 별도 캡처해 상태 전환을
  검증했다.
- status bar 시간과 source blur 품질은 metrics 대상에서 제외하려고
  위 177 px, 아래 102 px를 mask했다.

## Figma variant 선택

- 체험 실행은 여러 과거 variant 중 version
  `2379679754802507594`의 `2753:9706`을 canonical로 삼았다.
- `2092:4538`, `2092:4605`, `2323:3246`, `2323:3265`는 source
  추적을 위해 원본만 보존하고 canonical pixel 판정에는 사용하지 않았다.
